演出实操手册 + 串词模板

每场演出前翻一遍 · 鼓手是时间锚，主唱是情绪锚，乐队跟鼓走 · 弹错不停，副歌有动作，串词说完就进歌

PART 1 · 演出实操手册（演出前3天填）

三个最重要的规矩（所有人）

  1. 每首歌开始前，鼓手心里数4拍，点一下头，大家再一起进。 不要抢。
  2. 谁错了都不要停。 观众听不出来，你一停全场都知道。
  3. 副歌主唱一定要有动作（走台边/指/举手/蹲下）。站桩 = 白唱。

排序原则：前2首要5秒钩子 → 中段换风格 → 1个能量峰值 → 1个喘息低谷 → 再拉1次满 → 慢歌收尾。

怎么开始/结束每首歌

开始3步：①鼓手心里数4拍（不出声），点一下头或抬鼓棒 ②其他人看到信号再进 ③键盘/吉他先弹前奏的，弹完鼓手还是要点头示意"一起进"

乱了怎么办：鼓手重重敲2下军鼓，大家跟鼓走。其他人跟鼓不跟主唱。谁错了都不停。

结束：大家一起收，鼓手最后一下重音，同时停。安静1秒，主唱低头1秒→抬头→笑→说话。最后一首结束整队鞠躬。

演出前后清单

前一天晚上： - 不用节拍器按顺序完整跑1遍（崩了也跑完） - 单独练切分同步的歌×3遍 - 单独练安静后齐炸的歌×3遍 - 鼓手练"数4拍点头"信号，大家确认看懂 - 主唱背串词关键词（不背整句） - 检查设备：电池、鼓棒、备用弦、线材

时间不够时优先级：完整跑1遍 > 练同步 > 练齐炸 > 其他

演出当天： - 主唱开嗓20分钟（哼鸣+唇颤，不硬喊） - 吃七分饱，不喝冰/辣/奶 - 提前2小时到场装台试音（主唱和副歌分别试） - 和DJ/前一支乐队对衔接 - 提前30分钟换电池检查设备 - 提前10分钟全员围圈，鼓手领数一次4拍 - 提前3分钟主唱找台下1个具体的人

演出中：鼓手数4拍点头才进｜副歌主唱有动作｜3秒规矩｜串词≤40秒说完就进｜问完等3秒｜弹错不停｜笑

演出后：整队鞠躬｜留1人对接主办方｜当天填复盘系统

万一出意外

情况 怎么办
听不见话筒 前2个字声音加大，副歌回正常。笑比音准管用
调音不满意 装无所谓，笑
观众走散 看留下来的，给他们能量
时间被压缩 保底4首：1钩子+1风格+1合唱+1压轴
互动冷场 学小朋友跳一下，或指台下喊"来！"
紧张发抖 把发抖变成夸张动作，观众以为是投入
忘词 看手卡，不丢人
节奏漂了 鼓手敲2下军鼓拉回

主唱状态急救（上场前紧张时看）：①找1个人：锁定一个笑着的/举手机的/穿亮色衣服的人 ②深呼吸：吸4秒→屏2秒→呼6秒，做3次 ③第一句故意放慢50%，后面自然慢 ④想"聊天"不是"演出"

最终心法：你要的不是完美演出，是让观众觉得"这支乐队好玩"。控制能控制的（顺序/串词/动作），接受不能控制的（天气/人流），剩下的交给海风。

PART 2 · 通用串词模板（演出前1天填）

串词不是"报幕"，是"跟观众聊天"。要让观众觉得"台上这个人在跟我说话"，不是在背台词。

三条铁律

  1. 每段不超过40秒——说完笑点就进歌，别拖
  2. 问完问题等3秒再接——不等就不是互动，是自说自话
  3. 每段挂一个"锚点"——挂上首歌 / 挂台下某个人 / 挂场地天气主办方，不要硬找话

6种聊天话术（随时套）

类型 公式 举例
自嘲 说一个自己的小糗事 "刚才那段高音我练了一个月，今天就赌这一下"
指人 指台下1个具体的人+他的反应 "前排这位大哥点头了，看来这首歌戳到你了"
说场景 说场地/天气/环境的细节 "厦门这海风吹得我发型都没了"
假选择 问快的还是慢的，然后说"骗你的" "下一首快的还是慢的？——骗你们的，我选好了"
说主办方 提一下主办方，安全讨喜 "茅台请我们来的，你们喝了没？"
自问自答 问一个问题，不等回答自己接 "你们知道这首歌叫什么吗？……我也不知道，一起来"

3个绝对不要

  1. 不要问开放题——"你们开心吗？"没人答就尴尬。问就问"来不来？"
  2. 不要说"让我们休息一下"——改成"喘口气，听首慢的"
  3. 不要背台词——上场只记每段的1个关键词，现场自然说

8个位置的串词模板（填空用）

① 开场（上台第一段，30-40秒） 公式：打招呼 + 自嘲/说场景 + 提主办方 + "第一首你们都会" → 进前奏

"大家好！我们是【乐队名】。说实话站这儿比排练紧张多了——【场地/天气细节】。今天【主办方】请我们来，说是【活动主题】，【自嘲一句】。第一首歌你们一定都会——"

② 高能歌之间（20-30秒） 公式：接上首反应 + 假选择 + "走！" → 进前奏

"刚才那首【观众反应】——【一句评价】。下一首快的还是慢的？骗你们的，选好了。【一个要求，如'站着听'】！"

③ 换风格时（30-35秒） 公式：说场景 + 指人 + 引出风格 → 进前奏

"【场景感受，如'热不热？海风吹着舒服吧'】。下一首换风格，来点【风格名】。【指人】这位朋友点头了——这首歌叫【歌名】，【一个A/B问题】"

④ 情感歌之前（30-35秒） 公式：语气放柔 + 为什么改这首歌 + 共鸣问题 + "送给你们" → 进前奏

"下一首我得认真点。这首歌本来是【原版】，我们改成了【你们的版本】——因为【一句话理由】。你们有没有【共鸣问题】？心里想的也算。送给你们。"

⑤ 最炸的歌之前（25-30秒） 公式：提高音量 + "最炸的" + 让观众跟喊 + "走！" → 进前奏

"不煽情了！下一首是今晚最炸的——【观众范围】。副歌跟我一起喊【要喊的词】。来不来？"（等3秒）"行，够意思。走！"

⑥ 慢歌/喘息之前（25-30秒） 公式：说"喘口气"（不说"休息"）+ 场景联想 → 进前奏

"蹦够了，我也喘口气——你们别走，坐下来听首慢的。【场景画面】。【歌名】，听听看。"

⑦ 压轴之前（30秒） 公式：停2秒 + 真诚感谢 + 一个动作要求 → 进前奏

"最后一首了。"（停2秒，扫全场）"今晚谢谢你们留下来。【3个感谢对象】——都记住了。最后一首是慢歌，请你们做一件事：【动作，如'把手机灯打开'】。"（等灯亮）"谢谢。这首歌叫【歌名】，送给【送给谁】。"

⑧ 谢幕（15秒） 公式：感谢3方 + 报乐队名 + "下次见" + 鞠躬

"感谢【主办方】！感谢【场地】！感谢今晚所有留下来的人！我们是【乐队名】——下次见！"（整队鞠躬）

通用公式（歌与歌之间）：[接上首歌的反应] + [一个锚点/笑点] + [引出下首的一句话] + 进前奏

使用方式：演出前3天翻「演出手册」填歌单和分工 → 前1天翻「串词模板」写每首歌的串词关键词（不背整句）→ 演出中弹错不停、副歌有动作、串词≤40秒说完就进。
